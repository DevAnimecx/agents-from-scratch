# Assets

- `logo.svg` — minimal geometric Aspiro mark.
- `hero-banner.svg` / `hero-banner.png` — README hero artwork.
- `architecture.svg` / `architecture.png` — pipeline diagram source and preview.
- `demo-gif.svg` — reviewable terminal-demo artwork; `demo.gif` is a lightweight static export for previews.

The vector sources are kept beside raster previews so design changes remain easy to review. An animated screen recording can be exported for a release without adding a generated binary to the lesson source.
