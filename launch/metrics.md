# Launch measurement plan

Track only aggregated, consented signals:

| Signal | Source | Cadence |
| --- | --- | --- |
| stars, forks, contributors | GitHub Insights | weekly |
| docs page views and referrers | privacy-friendly analytics, if configured | weekly |
| package downloads | registry dashboard, if published | weekly |
| lesson completion proxy | optional localStorage only; never upload by default | none |
| community questions resolved | issue/Discord moderation log | weekly |

Do not call an AI citation an AEO success without recording the exact prompt, date, assistant, and cited URL. Do not purchase stars or scrape personal data.
