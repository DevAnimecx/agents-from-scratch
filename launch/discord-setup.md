# Discord setup checklist

This is a setup draft for maintainers; no Discord server is created by this repository.

## Channels

- `#welcome-and-rules`
- `#lesson-01-context` through `#lesson-20-regional-tools`
- `#show-your-agent`
- `#translations`
- `#maintainers`

## Safety

- Pin the MIT license, Code of Conduct, and security contact.
- Never ask members to paste API keys or personal data.
- Add a bot that links lesson issues but does not execute arbitrary code.
- Define moderator escalation, spam limits, and a deletion policy before inviting people.

## Welcome message

Build one primitive, run its test, and share what surprised you. Framework recommendations are welcome when they explain which hand-built problem they solve.
